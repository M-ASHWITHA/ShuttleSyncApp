# Design reference

The UI follows the mockups in `docs/design/` (colours sampled directly from them).

| Token | Value |
|-------|-------|
| Purple (brand, buttons, nav) | `#5b20b6` |
| Page background / tint | `#f7f4fb` / `#eeeafb` |
| Green (UPI, available, paid) | `#146c42` on `#e4f5ed` |
| Peach (cash waiting) | `#7c4a17` on `#fbeedd` |
| Pink / red (unpaid, full) | `#b5221a` on `#fce8e7` |
| Fonts | Space Grotesk (headings), IBM Plex Sans (body) |

Interaction polish: press/hover effects and ripple on every button, animated screen transitions, sliding bottom-nav bubble,
animated capacity ring and route progress, colour-coded selected states (stop tiles, route cards, UPI apps, waiting / onboard buttons).
